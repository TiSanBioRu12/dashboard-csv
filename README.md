# Dashboard de Visualización CSV

Aplicación web para cargar archivos CSV y generar gráficos interactivos.

## Integrantes
- Avilés Moreira Andy Gabriel
- Rubio Motoche Anthony Santiago

## Tecnologías
- Python + Flask
- Pandas
- Chart.js

## Instalación
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

## Uso
1. Abrir http://localhost:5000
2. Cargar un archivo CSV
3. Seleccionar tipo de gráfico y ejes
4. Clic en Generar
5. Exportar PNG si deseas
